# ⚡ Quick Start - Smart Hotel AI Concierge

## 🚀 Get Running in 3 Steps

### Step 1: Install
```bash
npm install
```

### Step 2: Set API Key
```bash
export OPENAI_API_KEY=sk-your-actual-openai-api-key
```

Get your API key from: https://platform.openai.com/api-keys

### Step 3: Run
```bash
npm run web
```

Open: **http://localhost:3000**

---

## 🎮 Try These Examples

Once running, try saying:

1. **"I want to order room service. I'm in room 305 and I'd like a burger and fries."**
2. **"Can someone clean my room? I'm in 412."**
3. **"I need 4 bath towels in room 208."**
4. **"I want to book a massage for 3 PM tomorrow. Room 501."**

## 📝 All Commands

```bash
npm run web     # Web interface (http://localhost:3000)
npm run chat    # CLI chat in terminal
npm run dev     # Simple demo example
npm run build   # Build for production
```

## 🐛 Troubleshooting

**"Cannot find package"**
```bash
npm install
```

**"Invalid API key"**
```bash
export OPENAI_API_KEY=sk-your-key-here
```

**"Port already in use"**
```bash
PORT=3001 npm run web
```
